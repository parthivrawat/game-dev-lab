## 🚀 Step-by-Step Start Guide

### Step 1: Install Godot (15-30 minutes)

1. **Read the setup guide**:
   - Open: `Resources/Theory/00-Setup-Guide.md`
   - This explains what Godot is and why we're using it

2. **Download Godot**:
   - Visit: https://godotengine.org/download
   - Download **Godot 4.x** (Standard version)
   - Extract to a convenient location (e.g., `E:\Games\Godot\`)

3. **Launch Godot**:
   - Run the executable
   - Familiarize yourself with the Project Manager

4. **Create a test project**:
   - Follow the guide to create your first project
   - Add a Label node with "Hello, Godot!"
   - Run it (F5)

✅ **Checkpoint**: Can you create and run a simple Godot project?

---

### Optional Step 1b: Install Ren'Py (15 minutes)

Since you're interested in **Adventure/RPG** games with story, we also have a **Ren'Py bonus track** for visual novels and narrative games.

1. **Read the Ren'Py guide**:
   - Open: `Resources/Theory/02-What-Is-RenPy.md`
   - Learn what visual novels are and when to use Ren'Py

2. **Download Ren'Py**:
   - Visit: https://www.renpy.org/
   - Download the latest version
   - Extract to a convenient location

3. **Create a test visual novel**:
   - Launch the Ren'Py launcher
   - Create a new project called `VN-Test-Project`
   - Run the sample

✅ **Checkpoint**: Can you create and run a simple Ren'Py visual novel?

### Step 2: Understand Game Fundamentals (30-45 minutes)

✅ **Checkpoint**: Can you explain the game loop in your own words?

## ✅ Ready to Begin?

You're ready to start when you can answer:

1. **What is a game engine?**
   <details><summary>Answer</summary>
   A software framework that provides pre-built systems for common game development tasks (rendering, physics, input, etc.)
   </details>

2. **Why are we using Godot?**
   <details><summary>Answer</summary>
   It's free, beginner-friendly, lightweight, supports 2D and 3D, and teaches concepts that transfer to any engine.
   </details>

3. **What are the three parts of a game loop?**
   <details><summary>Answer</summary>
   Input (read player actions), Update (apply game logic), Render (draw to screen)
   </details>

4. **What is game state?**
   <details><summary>Answer</summary>
   All the data that describes the current game situation (positions, scores, health, etc.)
   </details>
