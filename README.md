# Game Development Learning Lab — From 1D to 3D

Welcome to your comprehensive game development learning journey! This project will take you from complete beginner to creating your own 3D games.

## 🎯 Learning Objectives

By completing this lab, you will master:

### Programming Fundamentals
- Variables, data types, operators, conditions, loops
- Functions, parameters, and return values
- Arrays, lists, dictionaries, and data structures
- Object-oriented programming (classes, objects, inheritance)
- Events, callbacks, and signals
- Modular code and reusable components
- Debugging, testing, and error handling
- Algorithms and problem-solving

### Game Development Core
- Game loops and frame updates
- Input handling (keyboard, mouse, controllers)
- Game states and scene management
- Collision detection and response
- Movement, physics, and controls
- Scoring, lives, health, and timers
- Game difficulty and balancing
- Player feedback and game feel
- Save/load systems

### Mathematics & Physics
- Number lines and coordinate systems (1D, 2D, 3D)
- Vectors and vector operations
- Distance, direction, and angles
- Trigonometry basics
- Velocity, acceleration, and friction
- Gravity and jumping mechanics
- Collision mathematics
- Delta time and frame-rate independence
- Interpolation and camera movement

### Software Engineering
- Project organization and structure
- Naming conventions and code style
- Version control with Git
- Writing readable and maintainable code
- Refactoring techniques
- Testing individual systems
- Documentation practices
- Feature planning and scope management

## 🛠️ Technology Stack

- **Language**: GDScript (Python-like, beginner-friendly)
- **Engine**: Godot (free, open-source, powerful)
- **Version Control**: Git
- **Editor**: Godot Script Editor

## 📚 Learning Stages

### Stage 0: Foundations
**Focus**: Programming and game development basics
- What is a game?
- What is a game loop?
- Variables, functions, conditions
- Basic input handling
- **Deliverable**: Simple text-based interactive program

### Stage 1: 1D Games (Logic & State)
**Focus**: Game logic without complex graphics

1. **Number Guessing Game** - Variables, loops, conditions, random numbers
2. **1D Catch the Target** - Position, movement, boundaries, distance
3. **1D Pong** - Velocity, collision, scoring, game states
4. **1D Endless Runner** - Spawning, timers, difficulty curves

### Stage 2: 2D Games (Graphics & Spatial Movement)
**Focus**: 2D coordinate systems and visual gameplay

5. **2D Clicker Game** - Mouse input, UI, events, timers
6. **2D Pong** - 2D vectors, physics, collision detection
7. **Snake** - Arrays, grid movement, self-collision
8. **Breakout** - Multiple objects, level design, lives
9. **Top-Down Collect-and-Escape** - Tilemaps, enemies, collectibles
10. **2D Platformer** - Gravity, jumping, character controllers, camera

### Stage 3: 2D Advanced (Systems & Design)
**Focus**: Complex game systems

11. **Asteroids-Style Space Shooter** - Rotation, projectiles, screen wrapping
12. **Simple Tower Defense** - Pathfinding, waves, economy, upgrades

### Stage 4: 3D Games (Understanding Depth)
**Focus**: Three-dimensional game development

13. **Roll-a-Ball** - 3D coordinates, camera, lighting, physics
14. **Maze Explorer** - 3D movement, first/third-person camera, triggers
15. **Mini Racing Game** - Vehicle physics, checkpoints, lap counting
16. **Mini Adventure Game** - Interaction, inventory, quests, dialogue

### Capstone Project
**Your own original game** combining learned systems

## 🎓 Learning Approach

### Teaching Philosophy
1. **Theory Before Implementation** - Understand concepts before coding
2. **Gradual Complexity** - Small, manageable steps
3. **Active Learning** - You implement, not just copy
4. **Playable Results** - Every game is complete and fun
5. **No Unnecessary Complexity** - Simple first, advanced later

### Each Game Follows This Process
1. **Understand** - Discuss the game concept
2. **Plan** - Design document and feature list
3. **Build** - Minimum playable prototype
4. **Learn** - Theory behind the implementation
5. **Practice** - Exercises and modifications
6. **Test** - Manual testing checklist
7. **Improve** - Add optional features
8. **Reflect** - What did you learn?

## 📖 Quality Requirements

Each completed game must include:
- ✅ Clear title and start screen
- ✅ Playable core mechanics
- ✅ Basic user interface
- ✅ Win/lose conditions
- ✅ Restart functionality
- ✅ Readable, organized code
- ✅ README with run instructions
- ✅ System explanation
- ✅ Future improvement ideas

## 🎯 Success Criteria

You're ready to advance when you can:
- Explain the main concepts in your own words
- Read and understand the code
- Modify features independently
- Debug simple issues
- Design new features before implementing

## 💡 Remember

- **Simple > Complex** - Start small, build up
- **Playable > Perfect** - Working game beats perfect code
- **Questions Welcome** - No question is too basic
- **Experiment Freely** - Breaking things teaches lessons
