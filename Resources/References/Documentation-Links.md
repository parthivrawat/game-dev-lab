# Documentation & Learning Links

docs are the source of truth; everything else explains or inspires.

## 🧰 Communities (when you're stuck)

| Place | Link | Good for |
|-------|------|----------|
| Godot Q&A | https://ask.godotengine.org/ | Specific error/how-to questions |
| r/godot | https://www.reddit.com/r/godot/ | Discussion, feedback, inspiration |

**Asking well**: state what you tried, include the *exact* error text,
name your Godot version. (See `06-Debugging-and-Testing.md` → "When
You're Really Stuck".)
