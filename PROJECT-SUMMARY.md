**Topics**:

- Game loops (Input → Update → Render)

- Game states

**Deliverable**: Simple text-based interactive program

## 🎯 Learning Approach

### Teaching Philosophy

1. **Theory Before Implementation**
   - Understand concepts before coding
   - Know the "why" not just the "how"

2. **Gradual Complexity**
   - Small, manageable steps
   - Master basics before advancing
   - One new concept at a time

3. **Active Learning**
   - You implement, not just copy
   - Exercises and challenges
   - Modify and experiment

4. **Playable Results**
   - Every game is complete and fun
   - No half-finished prototypes
   - Build confidence with working projects

5. **No Unnecessary Complexity**
   - Simple first, advanced later
   - Use what you need, when you need it
   - Avoid premature optimization

### Each Game Follows This Process

1. **Understand** - Discuss the game concept
2. **Plan** - Create design document
3. **Build** - Implement minimum playable version
4. **Learn** - Study theory behind implementation
5. **Practice** - Exercises and modifications
6. **Test** - Manual testing checklist
7. **Improve** - Add optional features
8. **Reflect** - What did you learn?
